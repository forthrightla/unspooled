# Unspooled Visualizer

Next.js static site with Wrapped-style visualizations of your complete listening history.

**Part of the [Unspooled](../../README.md) project.**

## Quickstart

This package is typically used via the root Makefile:

```bash
# From repo root
make dev      # Start development server
make build    # Build static site
```

For standalone use:

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build static site
npm run build
```

## Data

The visualizer reads JSON files from `public/data/`. These are generated by the exporter:

```bash
# From repo root
make export
```

## Pages

- `/` - Overview dashboard with lifetime stats
- `/artists` - Browse all artists
- `/artists/[id]` - Artist detail with timeline
- `/albums` - Browse all albums  
- `/albums/[id]` - Album detail
- `/story` - Year selection for Wrapped-style stories
- `/story/[year]` - Year-in-review slides
- `/timeline` - Monthly listening history
- `/discoveries` - Artist discovery tracking
- `/patterns` - Temporal listening patterns
- `/search` - Full-text search

## Tech Stack

- **Framework**: Next.js 16 (static export)
- **Styling**: Tailwind CSS 4
- **Charts**: Recharts, D3
- **Animation**: Framer Motion
- **Search**: Fuse.js
- **Icons**: Lucide React

## Deployment

The site builds to `out/` as static HTML. Deploy to any static host:

```bash
npm run build
# Deploy out/ to Netlify, Vercel, GitHub Pages, etc.
```

See `netlify.toml` for Netlify-specific configuration.
